# topics.txt - what your next videos are about
# ---------------------------------------------
# One topic per line. Blank lines and lines starting with '#' are ignored, and
# duplicates are skipped (case-insensitive).
#
# How it is used:
#   * `autoshorts make` / `batch` take the first topic that has not been used yet,
#     top to bottom. A topic counts as used only after its video rendered successfully
#     (history: state/used_topics.json).
#   * When every topic here is used, autoshorts picks from its built-in list of ideas
#     (`autoshorts topics list --ideas` shows them).
#   * Add topics from the command line: autoshorts topics add "Why cats purr" "How GPS works"
#   * One-off video on anything: autoshorts make --topic "How bees make honey"
#
# The video format (facts, story, quiz, motivation, explainer) is chosen by
# script.format in config.yaml or --format, not here; write topics that fit the format
# you post most. Specific beats vague: "Why octopuses have three hearts" makes a better
# video than "octopuses".
#
# Note: custom topics need an LLM (Ollama or a free API key, see README). Without one,
# the offline script bank only covers the subjects it ships with.
